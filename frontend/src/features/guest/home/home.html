RATTS


made with Rust, Axum and Tokio, supporting any TypeScript UI


RATTS is a DevOps ready, starter web application featuring stateless JWT authentication and deferred persistence user registration, written in Rust with axum, tokio, SQLx, argon2, and lettre. It contains an Angular frontend with the typical public/private split found in most modern web apps. It uses PostgreSQL with one user table and migration support.

Deploy it locally with Docker:


git clone https://github.com/gameinstance/ratts.git
cd ratts
cp -v .env.template .env
docker-compose up --build

and test it on http://localhost:3000, verifying email expedition with mailcatcher at http://localhost:1080.
